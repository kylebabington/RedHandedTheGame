# The Evidence Room

An unofficial interactive mystery game concept inspired by investigative storytelling associated with RedHanded.

**This project is not affiliated with or endorsed by RedHanded.**

## Status

Milestone 0 — project foundation (tooling, documentation, minimal application shell).

Authoritative specification: [`docs/MASTER_PLAN.md`](docs/MASTER_PLAN.md)

## Stack

React 19 · TypeScript (strict) · Vite · Tailwind CSS v4 · React Router · Zustand · Zod · Motion · Vitest · Testing Library · Playwright · ESLint · Prettier

## Setup

```bash
npm ci
npm run dev
```

## Scripts

| Script | Purpose |
| --- | --- |
| `npm run dev` | Development server |
| `npm run build` | Production build |

| `npm run lint` | ESLint |

| `npm run test` | Vitest watch |
| `npm run test:run` | Vitest single run |
